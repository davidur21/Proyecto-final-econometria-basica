# Proyecto-final-econometria-basica
Proyecto final del curso Econometría Básica 2026-II — Grupo A2: confianza institucional ante emergencias. Incluye encuesta, base de datos, tablero Shiny y reporte.
# Participantes: 
Kevin Alexander Carrillo Garzón, David Steven Pascagaza Rodríguez, Luna Valentina Pinilla Malaver, Tomás Rangel Palacio, Luis Fernando Rodríguez Guevara.

## Estructura del Repositorio
El repositorio está organizado por etapa del proyecto: Encuesta/ contiene el diseño del cuestionario, Data/ separa los datos crudos de los ya procesados, Scripts/ documenta la limpieza de datos, Shiny_App/ tiene el código del tablero interactivo, y Reporte/ el análisis final de hallazgos.
```
Proyecto-final-econometria-basica/
Data/
  datos_crudos.csv
  datos_limpios.csv
Encuesta/
  diseno_preguntas.md
Reporte/
  reporte_hallazgos.pdf
Scripts/
  limpieza_datos.R
Shiny_App/
  app.R
README.md
```
